# 상세페이지 분할 및 초경량 WebP 압축기 (Detail Slice Compressor)

오픈마켓(네이버 스마트스토어, 쿠팡 등) 셀러를 위한 **100% 클라이언트 사이드 단일 페이지 웹 애플리케이션(SPA)**입니다.  
사용자의 이미지가 외부 서버로 전송되지 않고 브라우저 HTML5 Canvas API를 통해 초고속으로 메모리 최적화 분할 및 WebP 압축되어 ZIP 패키지로 다운로드됩니다.

---

## 🌟 주요 기능 및 특징

1. **초대형 이미지 브라우저 메모리 최적화**
   - 세로 30,000px 이상의 초대형 상세페이지도 브라우저 Canvas 메모리 초과(크래시) 없이 처리
   - 오프스크린 캔버스로 단일 슬라이스 조각 단위로 렌더링 후 즉시 Blob 변환 및 메모리 해제

2. **오픈마켓 최적 규격 원클릭 프리셋**
   - **네이버 스마트스토어**: 가로 860px 리사이즈, 세로 4,000px 단위 슬라이스
   - **쿠팡 기본**: 가로 780px 리사이즈, 세로 3,000px 단위 슬라이스
   - **쿠팡 고해상도**: 가로 1,000px 리사이즈, 세로 3,000px 단위 슬라이스
   - **원본 가로 유지**: 가로 원본 크기 유지, 세로 3,000px 단위 슬라이스
   - 사용자 직접 입력(가로 폭, 세로 높이) 커스텀 조정 지원

3. **차세대 포맷 변환 및 즉시 압축**
   - WebP(초경량 추천) 및 JPG/JPEG 선택 지원
   - 50% ~ 100% 품질 슬라이더(기본값 85%)
   - 순번 파일명(`detail_01.webp`, `detail_02.webp`...) 자동 넘버링 및 JSZip 패키징 후 원클릭 브라우저 다운로드

4. **100% 서버리스 무인 보안**
   - 이미지 데이터가 서버로 전송되지 않으므로 디자인 기밀 및 소스 안전 보장
   - 오프라인 환경에서도 작동 가능

5. **셀러 필수 추천 아이템 제휴 UI**
   - 우체국 규격 택배박스, 감열 송장 롤 라벨지(5030), 완충재 뽁뽁이 추천 카드
   - 공정거래위원회 필수 표기 문구 준수

## 🚀 로컬 실행 방법

Python 내장 서버 또는 Node.js 정적 서버를 통해 즉시 구동할 수 있습니다.

### 방법 1. Python 내장 서버
```bash
python -m http.server 3000 --directory public
```

### 방법 2. npx serve
```bash
npx serve public -l 3000
```

브라우저에서 `http://localhost:3000`에 접속합니다.

## ☁️ 배포 파이프라인 (Cloudflare Pages)

GitHub Actions 워크플로우 (`.github/workflows/deploy.yml`)가 준비되어 있습니다:
- `main` 브랜치에 푸시하면 자동으로 Cloudflare Pages에 정적 배포됩니다.
- GitHub Repository Secrets에 아래 값을 추가하세요:
  - `CLOUDFLARE_API_TOKEN`
  - `CLOUDFLARE_ACCOUNT_ID`
